# AR Biosciences Pro

AR Biosciences Pro is a child theme of the Genesis Framework, built from the Brief theme. This wiki covers how to set the theme up, what it adds to Genesis and WordPress, and how to work on it. The [README](https://github.com/UAMS-Web/ar-biosciences-pro/blob/main/README.txt) keeps the installation steps.
